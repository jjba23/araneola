* 0.2.9 (2026-11-21)

** Fixed

- The API reference is rendered with Texinfo 7.3, so dokgen's stylesheet
  applies: the page now has its index, its filter and its definition cards,
  like the [[https://github.com/jjba23/guile-dokgen][dokgen]] manual.  The
  manifest selected the bare =texinfo= binding (6.8), whose texi2any emitted
  the old definition structure, and nothing in the stylesheet matched it.

** Changed

- =channels.scm= pins the jointhefreeworld revision that carries
  guile-dokgen 0.9.2.

* 0.2.8 (2026-11-21)

** Changed

- =channels.scm= pins the jointhefreeworld revision that carries
  guile-dokgen 0.9.1.

** Fixed

- The API links point at =index.html=, the one page the reference has been
  since the dokgen migration, rather than at =.../API.html=.

* 0.2.7 (2026-11-21)

** Changed

- The API reference is generated by [[https://github.com/jjba23/guile-dokgen][guile-dokgen]]
  instead of guile-documenta.  The same modules and docstrings produce the
  reference, but every definition is a card with its signature, the index can
  be filtered, and the page has a light and a dark theme.
- =channels.scm= pins the latest Guix and jointhefreeworld revisions.  That is
  what makes guile-dokgen available, and it moves the rest of the collection
  the project builds against forward with it.

** Added

- =maak test= runs the suite against the in-process fixture site, so a
  checkout can be validated without remembering the invocation.
- =maak diagrams= renders the mermaid sources under =resources/diagrams/= to
  the SVGs the README shows.
- The README has a "How Araneola works" section, with a diagram of the crawl
  pipeline and one of how a sitemap index is chosen.
- The modes that carry the crawl and the sitemap writer explain themselves
  with the same diagrams in their commentary, so the API reference and the
  README tell one story.

** Fixed

- The docs task describes Araneola rather than Maak, which it had named since
  it was copied.
- Test logs are ignored by git, so a run leaves the tree clean.
